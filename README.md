## 📌 Project Overview

This project analyzes electric vehicle population data using Tableau
to understand EV adoption, manufacturers, vehicle types, geographic
distribution, electric range, and model-year trends.

The project transforms raw EV registration data into an interactive
dashboard that provides meaningful insights into electric vehicle
adoption patterns.

---

## 🎯 Objectives

- Analyze total electric vehicle registrations
- Compare BEV and PHEV adoption
- Identify leading EV manufacturers
- Analyze EV distribution by state and city
- Identify popular EV models
- Analyze electric range
- Study EV registrations across model years
- Analyze CAFV eligibility
